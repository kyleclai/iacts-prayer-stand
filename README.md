# IACTS Prayer Stand

This repository is initialized for an **IACTS Catholic prayer stand** focused on vacation prayer practice.

## What IACTS Means

- **I**: Invitation
- **A**: Adoration
- **C**: Contrition (Confession)
- **T**: Thanksgiving
- **S**: Supplication
